## 2026-03-30 - Tkinter Password Entry Toggle UX
**Learning:** Adding a visible show/hide toggle alongside obscured entry fields (such as App Passwords or API keys) in desktop GUIs significantly reduces authentication errors caused by hidden typos while preserving default masking.
**Action:** Always pair masked sensitive input fields with an inline toggle button that updates both input mask (`show`) and visual text indicator ("👁 Show" / "🙈 Hide").
